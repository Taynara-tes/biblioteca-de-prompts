# Planejamento de conteúdo para redes sociais

## Objetivo

Criar um post coerente com o público, a plataforma e o objetivo da comunicação.

## Prompt

```text
Atue como estrategista de conteúdo.

Tema: [TEMA]
Objetivo: [OBJETIVO]
Público: [PÚBLICO]
Plataforma: [PLATAFORMA]
Tom de voz: [TOM]
Chamada para ação: [CTA]

Crie:
1. uma ideia central;
2. três opções de título;
3. o texto completo do post;
4. uma chamada para ação natural;
5. cinco sugestões de hashtags relevantes;
6. uma orientação visual curta.

Evite clichês, promessas exageradas e informações não verificadas.
```
