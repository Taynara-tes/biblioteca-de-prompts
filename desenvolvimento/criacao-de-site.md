# Criação de site

## Objetivo

Planejar e criar um site completo, responsivo, acessível e alinhado à identidade do projeto.

## Quando usar

Use este prompt para criar landing pages, sites institucionais, portfólios, páginas de serviços ou outros sites de pequeno e médio porte.

## Variáveis

- `[TIPO DE SITE]`: landing page, portfólio, site institucional ou outro formato
- `[NOME DO PROJETO]`: nome da marca, empresa ou iniciativa
- `[OBJETIVO PRINCIPAL]`: ação ou resultado esperado do site
- `[PÚBLICO-ALVO]`: perfil das pessoas que visitarão o site
- `[CONTEÚDO]`: textos, produtos, serviços e informações disponíveis
- `[IDENTIDADE VISUAL]`: cores, tipografia, referências e estilo desejado
- `[TECNOLOGIA]`: linguagem, framework ou plataforma preferida
- `[REQUISITOS]`: páginas, seções, integrações e funcionalidades obrigatórias

## Prompt

```text
Atue como estrategista de produto, designer UX/UI e desenvolvedor web experiente.

Crie um [TIPO DE SITE] para [NOME DO PROJETO].

Contexto:
- Objetivo principal: [OBJETIVO PRINCIPAL]
- Público-alvo: [PÚBLICO-ALVO]
- Conteúdo disponível: [CONTEÚDO]
- Identidade visual: [IDENTIDADE VISUAL]
- Tecnologia preferida: [TECNOLOGIA]
- Requisitos obrigatórios: [REQUISITOS]

Antes de começar, analise as informações fornecidas. Se faltar algo essencial para definir a estrutura, o conteúdo ou a implementação, faça no máximo cinco perguntas objetivas. Caso seja possível avançar com segurança, declare brevemente as suposições adotadas.

Desenvolva o site considerando:
- hierarquia visual clara e navegação intuitiva;
- design responsivo para celular, tablet e desktop;
- textos objetivos, com chamadas para ação coerentes;
- acessibilidade, incluindo HTML semântico, contraste, foco visível e textos alternativos;
- desempenho, SEO básico e boas práticas de segurança;
- componentes reutilizáveis e código organizado;
- estados de interação, carregamento, vazio e erro quando aplicáveis;
- ausência de dados pessoais, segredos ou dependências desnecessárias.

Entregue:
1. resumo da estratégia e da estrutura do site;
2. mapa das páginas ou seções;
3. direção visual sugerida;
4. implementação completa e pronta para execução;
5. instruções curtas para instalar, executar e personalizar;
6. lista de verificações realizadas.

Não use textos genéricos como "Lorem ipsum". Quando o conteúdo real não tiver sido fornecido, escreva uma sugestão coerente e identifique-a como conteúdo provisório. Não invente depoimentos, clientes, certificações, preços ou resultados.
```

## Exemplo de uso

Crie uma landing page para uma confeitaria artesanal chamada Doce Aurora. O objetivo principal é receber encomendas pelo WhatsApp. O público-alvo são pessoas de 25 a 50 anos que procuram bolos personalizados em São Paulo. Use tons de creme, terracota e marrom, com aparência acolhedora e elegante. A página deve incluir apresentação, produtos, processo de encomenda, perguntas frequentes e chamada para contato. Use HTML, CSS e JavaScript sem frameworks.

## Resultado esperado

A resposta deve apresentar uma proposta coerente com o público e o objetivo do projeto, seguida de uma implementação funcional, responsiva e fácil de personalizar. O site deve poder ser executado com as instruções fornecidas e não deve depender de conteúdo ou credenciais inventadas.
