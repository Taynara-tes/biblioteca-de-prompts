# Revisão de código

## Objetivo

Identificar problemas e sugerir melhorias de forma prática e priorizada.

## Prompt

```text
Atue como revisor de código experiente em [LINGUAGEM OU TECNOLOGIA].

Contexto do projeto:
[CONTEXTO]

Código:
[COLE O CÓDIGO]

Revise considerando:
- erros de funcionamento;
- segurança;
- legibilidade;
- desempenho;
- tratamento de erros;
- testes ausentes;
- aderência às convenções da tecnologia.

Classifique cada problema como crítico, importante ou melhoria. Para cada item, explique o impacto e apresente uma correção objetiva. Não proponha mudanças meramente estéticas sem benefício claro.
```
