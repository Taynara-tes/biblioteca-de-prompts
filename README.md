# Biblioteca de Prompts

Coleção de prompts reutilizáveis para inteligência artificial, organizada por objetivo e área de aplicação.

A proposta deste repositório é reunir instruções claras, testáveis e fáceis de personalizar para tarefas de atendimento, automação, criação de conteúdo, desenvolvimento e produtividade.

## Categorias

| Categoria | Uso |
| --- | --- |
| [Atendimento](./atendimento/) | Respostas claras, empáticas e alinhadas ao contexto do cliente |
| [Automações](./automacoes/) | Planejamento e documentação de processos automatizados |
| [Criação de conteúdo](./criacao-de-conteudo/) | Ideias, roteiros e planejamento editorial |
| [Desenvolvimento](./desenvolvimento/) | Revisão, explicação e melhoria de código |
| [Produtividade](./produtividade/) | Planos de ação, priorização e organização |
| [Templates](./templates/) | Estruturas para criar novos prompts |

## Como usar

1. Escolha uma categoria.
2. Abra o prompt desejado.
3. Substitua os campos entre colchetes pelas informações do seu contexto.
4. Execute o prompt na ferramenta de IA escolhida.
5. Revise o resultado antes de utilizá-lo ou publicá-lo.

## Estrutura de um bom prompt

Um prompt desta biblioteca procura apresentar:

- **Objetivo:** o resultado que se deseja alcançar;
- **Contexto:** as informações necessárias para a tarefa;
- **Instruções:** o que a IA deve fazer;
- **Restrições:** limites, tom e cuidados;
- **Formato de saída:** como a resposta deve ser organizada;
- **Critérios de qualidade:** o que define um bom resultado.

## Boas práticas

- Forneça contexto suficiente e informações verificáveis.
- Especifique público, tom e formato esperado.
- Use exemplos quando houver risco de ambiguidade.
- Revise respostas antes de tomar decisões importantes.
- Nunca publique senhas, chaves de API, dados pessoais ou informações confidenciais.
